## 5. 게임 디자인 핵심 결정

### 5-1. 코어 루프 (Core Loop)
- **순간 루프 (30초)**: 이동 + 근접/원거리로 좀비 처치 → 생존
- **단기 루프 (5-15분)**: 웨이브 클리어 → 업그레이드 카드 선택 → 다음 웨이브
- **장기 루프**: 강해지는 빌드로 보스까지 클리어 / 다른 업그레이드 조합 시도

### 5-2. 게임 필러 (Game Pillars)
> 모든 디자인 판단의 기준이 되는 핵심 원칙 3-4개

1. **압도**: 수백 마리 좀비 대군에 둘러싸이는 스케일감
2. **성장**: 웨이브마다 강해지는 업그레이드 빌딩의 재미
3. **타격감**: 근접+원거리 전투의 묵직한 피드백

### 5-3. 안티 필러 (Anti-Pillars)
> 이 게임이 절대 하지 않는 것들

- NOT 멀티플레이 (4주 일정, 싱글 확정)
- NOT 스텔스 / 은신 (파워 판타지와 반대)
- NOT 스토리 컷씬 (범위 초과)

## 5-4. MVP 범위 (확정)

### 넣는 것 ✅
- 플레이어 이동 + 원거리 사격
- 근접 전투 (기본 콤보 1~2개)
- 좀비 웨이브 (5라운드)
- 좀비 타입 3종 (일반 / 돌진형 / 탱커형)
- 웨이브 클리어 후 업그레이드 카드 선택 (3장 중 1개)
- 보스 1마리 (5라운드)
- 아레나 맵 1개
- 메인 메뉴 + 기본 HUD

### 절대 안 넣는 것 ❌
- 멀티플레이
- 랜덤 맵 생성
- 스토리 / 컷씬
- 세이브 시스템

## 5-5. 주요 작업물

### 캐릭터 시스템
- 플레이어 이동 (WASD + 회전)
- 원거리 사격 (조준, 발사, 탄창)
- 근접 전투 (기본 콤보 1~2개, 히트박스)
- 피격 + 사망 처리 / 체력 시스템

### 적 AI
- 좀비 기본형 (추적 + 공격)
- 돌진형 (빠르고 약함)
- 탱커형 (느리고 체력 많음)
- 보스 (패턴 2개)
- 스폰 매니저 (웨이브별 수량 / 타입 비율)

### 업그레이드 시스템
- 업그레이드 카드 데이터 (5~8종)
- 카드 선택 UI (웨이브 클리어 후 3장 제시)
- 스탯 적용 로직 (데미지 / 속도 / 체력 등)

### 게임 루프
- 웨이브 매니저 (5라운드 에스컬레이션)
- 라운드 클리어 / 실패 조건
- 게임 오버 + 결과 화면

### 레벨 / 맵
- 아레나 맵 1개 (스폰 포인트, 장애물 배치)

### UI / UX
- 메인 메뉴
- HUD (체력바, 탄약, 현재 웨이브)
- 업그레이드 카드 선택창
- 게임 오버 / 클리어 화면

### 비주얼 / 오디오
- UE 마켓플레이스 에셋 선정 + 통합
- 총격 / 근접 타격 VFX
- 좀비 사망 이펙트
- BGM 1트랙 + 기본 SFX
