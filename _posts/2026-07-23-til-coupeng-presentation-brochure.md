팀 프로젝트 최종 발표가 다가와서, 이날은 코드 대신 **발표 PPT 템플릿과 브로셔**를 준비했다. 발표 자료 파일은 `8조 발표 ppt.pptx` — 26슬라이드, 7/21 v0.2.0 빌드 기준, 시연 영상 3본을 품어 739MB짜리다. **내 기여는 PPT 템플릿 제작·발표자료 준비·브로셔 작성**이고, 각 파트 슬라이드의 내용은 팀원들의 작업이다.

## COUPENG — 쿠팡 패러디 브랜드 템플릿

템플릿의 얼굴은 **COUPENG**이다. 쿠팡을 패러디한 브랜드 아이덴티티로, 크림 배경에 파랑/노랑 로고 타이포, 바코드·택배 모티프, 그리고 펭귄 마스코트를 얹어 "이사(택배) 게임"의 톤을 잡았다. 표지에는 로고 아래 "이삿짐을 안전하게 이삿짐 트럭에 옮겨라!"라는 카피와 팀 정보(TEAM 8조 캐리 / 2026.07.21 / v.0.2.0)를 바코드 모티프와 함께 배치했다.

![목차 레이아웃](/assets/img/til/2026-07-23/ppt-toc-template.png)
_목차 장 — 크림 배경 + 카드형 리스트 + 펭귄 일러스트로 템플릿 규격 통일_

템플릿을 먼저 규격으로 못 박아 두면, 파트별 슬라이드를 팀원들이 나눠 만들어도 발표 전체의 톤이 흐트러지지 않는다. 목차 장의 카드형 리스트가 그 규격의 기준이 됐다.

## 발표 구성 — 26슬라이드의 흐름

발표 구성은 슬라이드 제목 실측 순서로 이렇다: 프로젝트 소개 → 팀 구성 → 게임 시연 → UI → 멀티플레이(방 코드) → 레벨·스테이지 → 포스트 프로세싱(수식으로 그린 만화 하늘) → 가구 오브젝트·데이터 테이블 → 협동 운반 → 가구 파괴 → 상태 변화 → 세션 유지 → 실시간 점수 → 트러블슈팅 → 팀원 후기 → Q&A.

![트러블슈팅 장](/assets/img/til/2026-07-23/ppt-troubleshooting.png)
_트러블슈팅 장 — 러버밴딩(고무줄 튕김)을 "보이지 않는 목줄"(리쉬)로 잡은 사례를 Before/After로 구성 (사례 자체는 [7/15 TIL](/posts/til-carry-leash-movement/) 참조)_

트러블슈팅 장은 발표에서 기술적 깊이를 보여주는 자리라, 문제 상황과 해결을 Before/After 대비로 구성했다.

## 브로셔 — 노션 한 장으로 프로젝트 소개

브로셔는 노션 페이지 "8조 프로젝트(CouPeng) 브로셔"로 작성했다. 구성은 프로젝트 소개(이미지) → 게임 소개(핵심 메커니즘 3가지 — 협력 물리 / 환경 퍼즐·파괴 / 스테이지 선택) → 게임 개요 표(캐주얼·코옵, Steam, 2026.06.01~07.21 약 8주, 팀 6명, UE 5.8.0, C++) → 핵심 기능·기술·기술적 의사결정·트러블슈팅 DB → 팀 구성 표. 팀 구성 표 기준 나는 **팀장, Network/게임플레이 담당**이다.

![브로셔 소개 이미지](/assets/img/til/2026-07-23/brochure-cover.png)
_노션 브로셔의 프로젝트 소개 이미지 — CouPeng 로고와 이삿짐을 트럭에 옮기는 펭귄들_

> **오늘 배운 것**
> - 발표 자료도 **규격을 먼저** 만든다 — 템플릿(색·타이포·카드 레이아웃)을 못 박아 두면 파트별로 나눠 만들어도 톤이 유지된다
> - 발표 구성은 게임의 플레이 순서(입장→플레이→시스템→회고)를 따라가면 자연스럽다 — 트러블슈팅 장은 Before/After 대비가 가장 힘이 세다
> - 브로셔는 발표 PPT의 요약이 아니라 **다른 독자(발표를 못 본 사람)를 위한 독립 문서**로 — 개요 표와 메커니즘 3줄이 먼저다
