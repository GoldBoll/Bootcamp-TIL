> 출처: <https://www.acmicpc.net/problem/2606>

```cpp
// 백준 2606 - 바이러스
// https://www.acmicpc.net/problem/2606

// 문제 설명
// 1번 컴퓨터가 웜 바이러스에 걸렸을 때
// 1번과 직접/간접 연결된 컴퓨터 수를 구하라

// 접근
// - 인접 리스트로 그래프 구성
// - DFS로 1번부터 탐색 → 방문한 노드 수 - 1 출력

#include <iostream>
#include <vector>
using namespace std;
#define endl '\n'

vector<int> v[104];
bool visi[104];

int dfs(int here)
{
    visi[here] = true;
    int cnt = 1;
    for (int i : v[here])
        if (!visi[i])
            cnt += dfs(i);
    return cnt;
}

int main()
{
    int n, m, a, b;
    cin >> n >> m;
    while (m--)
    {
        cin >> a >> b;
        v[a].push_back(b);
        v[b].push_back(a);
    }

    cout << dfs(1) - 1 << endl;
    return 0;
}
```

## 정리

- 1번 노드에서 DFS 한 번으로 연결된 컴포넌트 전체를 탐색한다.
- `int dfs()`가 자기 자신 포함 연결 노드 수를 반환하므로 `-1`로 1번 자신을 제외하면 답이다.
- 양방향 그래프 — "네트워크 상에서 연결된 쌍"이므로 `v[a] ↔ v[b]` 양쪽 모두 push.

> **오늘 배운 것** — DFS를 int 반환으로 만들면 탐색과 동시에 연결된 노드 수를 얻는다. 자기 자신을 포함해 세므로 시작 노드를 빼는 `-1` 보정이 필요하고, "연결된 쌍"이라는 문장에서 양방향 그래프임을 읽어야 한다.
{: .prompt-tip }

> **면접에서 이렇게 말한다** — 예상 질문: "특정 노드와 직·간접으로 연결된 노드를 모두 찾으려면 어떻게 합니까?" → 인접 리스트, DFS 탐색, visited 배열, 컴포넌트 크기 반환, 시작 노드 제외
