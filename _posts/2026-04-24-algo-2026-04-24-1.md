```cpp
// 프로그래머스 Lv.1 - 행렬의 덧셈
// https://school.programmers.co.kr/learn/courses/30/lessons/12950
//
// [문제]  크기가 같은 두 행렬 arr1, arr2의 같은 위치 원소를 더한 행렬 반환
// [제약]  행과 열의 길이는 500 이하
// [입출력]  [[1,2],[2,3]],[[3,4],[5,6]] → [[4,6],[7,9]]
//
// 풀이: 같은 위치 원소를 순회하며 더함 — O(행*열)

#include <string>
#include <vector>

using namespace std;

vector<vector<int>> solution(vector<vector<int>> arr1, vector<vector<int>> arr2) {
    vector<vector<int>> answer = arr1;
    for (int i = 0; i < (int)arr1.size(); i++) {
        for (int j = 0; j < (int)arr1[i].size(); j++) {
            answer[i][j] += arr2[i][j];
        }
    }
    return answer;
}
```

> **오늘 배운 것** — 크기가 같은 두 행렬의 덧셈은 이중 루프로 같은 위치 원소를 더하면 끝난다. `answer`를 `arr1` 복사본으로 초기화하면 결과 행렬의 크기를 따로 잡을 필요가 없고, 시간 복잡도는 O(행×열)이다.
