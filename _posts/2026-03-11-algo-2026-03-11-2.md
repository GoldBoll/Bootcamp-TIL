아홉 개의 수를 입력받아 최댓값과 그 위치(1-based)를 출력하는 문제. `max_element`로 최댓값을 가리키는 반복자를 얻고, `begin()`과의 차이로 인덱스를 계산했다.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
  vector<int> nums(9);
  
  for (size_t i = 0; i < nums.size(); i++)
  {
    cin >> nums[i];
  }
  
  int idx = max_element(nums.begin(), nums.end())- nums.begin();

  cout << nums[idx] <<endl;
  cout << idx + 1 <<endl;
  return 0;
}
```

> **오늘 배운 것** — `max_element(begin, end)`는 최댓값의 반복자를 반환하므로, `begin()`을 빼면 인덱스가 나온다. 문제가 1-based 위치를 요구하면 `idx + 1`로 보정해서 출력한다.
