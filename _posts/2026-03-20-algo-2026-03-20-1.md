백준 10818 "최솟값과 최댓값" 풀이다. N개의 정수에서 최솟값과 최댓값을 출력한다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    int val, minVal, maxVal;
    cin >> val;
    minVal = maxVal = val;

    for (int i = 1; i < n; i++) {
        cin >> val;
        if (val < minVal) minVal = val;
        if (val > maxVal) maxVal = val;
    }

    cout << minVal << " " << maxVal << "\n";
    return 0;
}
```

값을 배열에 담지 않고, 첫 값으로 min/max를 초기화한 뒤 읽으면서 바로 비교해 갱신했다. 입력과 동시에 처리하는 단일 순회라 공간은 O(1)로 끝난다.

> **오늘 배운 것** — 모든 입력을 저장할 필요가 없는 문제는 읽으면서 바로 처리하는 단일 순회로 풀 수 있다는 것. min/max의 초기값은 임의 상수 대신 첫 입력값으로 잡으면 경계값 실수가 없다.
