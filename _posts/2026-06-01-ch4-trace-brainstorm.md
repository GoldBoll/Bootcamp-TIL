## 출발점

강동욱 튜터님이 *Chained Together*(플레이어들이 사슬로 묶여 함께 등반하는 협동 게임)를 8조에 제안했다. **리소스 부담이 낮아** 팀 규모로 현실적이라는 게 핵심. 여기에 **어몽어스식 배신자 1명**을 결합하는 것이 원 아이디어였다 — 방향만 있고 세부 메커닉은 전부 TODO.

## 크리에이티브 브리프

- **팀**: 8조, 이전에 게임을 출시해본 경험.
- **기간**: 약 8주 (2026-06-01 → 07-25 제출).
- **지향 정서**: Expression & Creativity — 정답 풀이가 아니라 플레이어마다 다른 전략·관계가 창발하는 경험.

→ **8주 + Expression**이면 "콘텐츠를 많이 찍는" 게임보다 **플레이어가 서로에게 콘텐츠가 되는 멀티플레이 이머전트 게임**이 정답. *적게 만들고 깊게 논다.*

## 방향을 튼 순간들 — 컨셉이 자리 잡기까지

브레인스토밍은 결국 **무엇을 버릴지 거듭 결정하는 과정**이었다. 처음의 협동 등반 + 배신자 아이디어가 아래 여덟 번의 방향 전환을 거쳐 지금의 "TRACE"로 좁혀졌다.

| 단계 | 무엇을 바꿨나 | 어디로 갔나 |
|---|---|---|
| 1 | 협동의 물리 손맛보다 **심리전**을 택함 (보드게임 co-op 결) | 손맛 → 두뇌 싸움 |
| 2 | 연기력 의존을 버리고 **시스템으로 굴러가는 깊이**로 | 연기 의존 컨셉 탈락 |
| 3 | 카드가 아닌 **실시간 3D 정보전**, 엔진 UE5.5+ 확정 | 비대칭 관제 구도 |
| 4 | **실시간 압박**을 핵심 긴장으로 | Keep Talking식 식은땀 |
| 5 | Clue의 추리는 살리되 격자를 **공간 수색**으로 | 격자 추리 → 공간 수사 |
| 6 | **"범죄자는 흔적을 남긴다"** + 은닉을 메커닉 축으로 | 포렌식 고양이-쥐 게임 |
| 7 | 보상 설계보다 **한 판의 재미**를 우선 | 위기→의심→수색→검거 리듬 |
| 8 | 무대는 **확보 가능한 에셋**에 맞춤 (메커닉은 무대 비의존) | asset-driven 결정 |

## 최종 컨셉 — TRACE(흔적)

**피치**: 고립 시설에서 실시간 위기를 협력 처리하는 중, 숨은 배신자가 남긴 **흔적**을 **수색**해 검거하는 협동 소셜 추리 게임. 승부는 연기력이 아니라 **수색 vs 은닉**이라는 시스템 행위로.

**4개 필러**

1. **흔적은 거짓말하지 않는다** — 색출은 물리적 증거 기반, 배신자도 정상 시스템만.
2. **수사는 발로 한다** — 진실은 구역 수색으로 좁힌다.
3. **아무도 전체를 못 본다** — 정보 분할, 협력 강제.
4. **시계는 멈추지 않는다** — 실시간 압박(필러 2와 의도적 충돌).

**보상 — 현상금 경제(Time Bounty)**: 정적 보상 표(소극 플레이 유발)를 버리고, *범행이 판돈을 키우는* press-your-luck 도박 엔진으로. 들키면 판돈이 결정적 증거 제공자에게 이전, 종반엔 "한탕 vs 잠적" 선택이 절정.

## 스코프 & 리스크

- 엔진 **UE5.5+** / **PC(Steam·Epic)** / 4~6인 / 한 판 30~60분.
- **🔴 1순위 리스크 = 네트워킹**: 실시간 리플리케이션 + 정보 비대칭의 서버 권위 + 치트 방지. → MVP를 좁게(맵1·위기3) 잡고 **네트워크 수직 슬라이스부터** 검증.

### 핵심 메커닉 (우리가 실제로 만들 5가지)

1. **비대칭 위기 대응** — 진단 판독 / 물리 복구(밸브·배선·부품·밀봉) / 제한 채널 교신
2. **사보타주 & 흔적 생성** — 정상 시스템의 오용이 현장에 물리적 흔적·범행 물품을 남김
3. **은닉 & 청소** — 배신자가 증거를 숨기거나 지움 (은닉 자체가 메타 흔적을 남길 수 있음)
4. **수색 & 감식 & 검거** — 구역 수색으로 증거 수집 → 감식으로 단서화 → 검거 시도
5. **현상금 경제(Time Bounty)** — 범행이 판돈을 키우고, 검거/도주에 따라 정산

### 핵심 루프

| 층위 | 내용 |
|---|---|
| **30초** | 위협 발생 → 현장이 관측 → 제한 채널로 교신 → 관제/복구가 처리. *배신자는 거짓 값 주입·복구 방해, 흔적이 남음.* |
| **5분** | 위기 여러 개 연속 처리해 한 구역 안정화 → 짧은 소강에 의심 공유·초기 수색 |
| **세션** | 여러 구역 + 누적 수사 → 종반 클라이맥스(**한탕 vs 잠적**) → 검거 시도 → 정산 |
| **진행** | 새 무대·위기·수법·난이도 해금. 성장은 파워가 아니라 **시스템 숙련** 중심 |

### MVP — "코어 루프가 재밌나"만 검증

1. 4~6인 네트워크 멀티(리슨 서버) + 배신자 1명 배정
2. 무대 1개 + 위기 타입 3종 (협력 복구 가능)
3. 사보타주 1세트 + 흔적/범행 물품 생성 + 은닉·청소
4. 구역 수색 + 감식 + 검거 + 오인 기소 페널티
5. 현상금 정산 + 결과 4분기(미션 성공/실패 ✕ 검거/도주)
