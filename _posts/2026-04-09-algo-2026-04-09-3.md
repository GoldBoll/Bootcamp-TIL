> 출처: <https://www.acmicpc.net/problem/1152>

```cpp
// 백준 1152 - 단어의 개수 (Silver V)
// https://www.acmicpc.net/problem/1152

// 문제 설명
// 영어 대소문자와 공백으로 이루어진 문자열에서 단어의 개수를 구한다.
// 단어는 공백 한 개로 구분되며, 문자열은 공백으로 시작하거나 끝날 수 있다.

// 입력
// 첫 줄: 영어 대소문자와 공백으로 이루어진 문자열 (길이 ≤ 1,000,000)

// 출력
// 첫째 줄에 단어의 개수 출력

// 입출력 예
// 입력:                              출력:
// The Curious Case of Benjamin Button    6
//  The first character is a blank        6
// The last character is a blank          6

#include <iostream>
#include <string>
using namespace std;

int main()
{
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int answer = 0;
    string word;
    while (cin >> word)
        answer++;
    cout << answer << "\n";
    return 0;
}
```

문자열이 공백으로 시작하거나 끝날 수 있다는 조건이 이 문제의 함정이다. `getline`으로 읽으면 앞뒤 공백을 직접 처리해야 하지만, `cin >> word`는 공백과 개행을 자동으로 건너뛰며 단어 단위로 읽기 때문에 엣지 케이스가 저절로 해결된다. `while (cin >> word)`는 EOF(입력 끝)에서 자동으로 false가 되어 종료 조건도 따로 필요 없다. 풀이 과정 전체는 [이날 TIL](/posts/til-2026-04-09/)에 정리했다.

> **오늘 배운 것** — 단어 세기의 진짜 난이도는 앞뒤 공백 처리다. `cin >>`의 공백 자동 skip과 EOF 자동 종료를 쓰면 트리밍 코드 없이 카운터 하나로 끝난다.
{: .prompt-tip }

> **면접에서 이렇게 말한다** — 예상 질문: "cin >>과 getline의 차이는 무엇인가요?" → 공백 구분자 vs 한 줄 전체, 앞뒤 공백 자동 무시 vs 직접 trim, EOF 시 false 반환, 입력 형태에 따른 선택
{: .prompt-info }
