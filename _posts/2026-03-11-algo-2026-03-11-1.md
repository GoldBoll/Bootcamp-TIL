두 정수를 입력받아 합을 출력하는 기본 입출력 문제. 문제 자체보다 cin/cout 입출력 형태를 손에 익히는 게 목적이었다.

```cpp
#include <iostream>
using namespace std;
int main()
{
  int a, b;
  cin >> a >> b;
  cout << a+b <<endl;
  return 0;
}
```
