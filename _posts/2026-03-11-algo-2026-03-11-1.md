두 정수를 입력받아 합을 출력하는 기본 입출력 문제. 문제 자체보다 cin/cout 입출력 형태를 손에 익히는 게 목적이었다.

```cpp
#include <iostream>
using namespace std;
int main()
{
  int a, b;
  cin >> a >> b;
  cout << a+b <<endl;
  return 0;
}
```

> **오늘 배운 것** — `cin >> a >> b`로 공백 구분 입력을 받고 `cout`으로 출력하는, C++ 문제 풀이의 가장 기본 골격을 확인했다.
{: .prompt-tip }

> **면접에서 이렇게 말한다** — 예상 질문: "C++에서 표준 입출력은 어떻게 처리하나요?" → iostream, cin/cout 스트림, >> << 연산자, endl 개행
