## 게임 장르 분석

핵심 콘셉트는 쿼터뷰 시점의 좀비 서바이벌에 익스트랙션 루프(맵에 진입해 파밍하고 탈출 지점으로 빠져나와야 전리품이 확정되는 구조)를 결합하는 것이다. 파밍 → 생존 → 탈출 → 은신처 강화 → 재진입의 반복 사이클이 게임의 뼈대가 된다.

### 장르 특성

| 특성 | 내용 |
| --- | --- |
| 핵심 재미 | 좀비 액션 · 소리 관리 · 파밍 · 은신처 운영 |
| 플레이 루프 | 맵 진입 → 파밍 & 퀘스트 → 탈출 → 은신처 관리 |
| 카메라 | 쿼터뷰 (Top-Down 45°) |
| 네트워크 | 개인 서버 기반 (좀보이드 방식) |

### 레퍼런스 게임 분석

레퍼런스는 다섯 개를 골랐다. 각 게임에서 참고할 지점과, 그대로 따라 하지 않고 바꿀 지점을 나눠 정리했다.

| 게임 | 참고 포인트 | 개선 / 차별화 |
| --- | --- | --- |
| 좀보이드 | 오픈월드 파밍 · 아이템 보관 구조 · 좀비 서바이벌 | 익스트랙션 루프 + 퀘스트 추가 / 타격감 개선 |
| 낙원 | 인벤토리 구조 · 파쿠르 · 맵 레이아웃 | 전투 모션 답답함 개선 / 은신처 시스템 고도화 |
| 타르코프 | 익스트랙션 포인트 · 퀘스트 · 루팅 오브젝트 배치 | 차량으로 먼 구역 파밍 이동 가능 |
| 레프트4 데드 | 좀비 타격감 · 피격 리액션 | 좀비 루팅 가능 / 선형 레벨 탈피 |
| SKYHILL | 건물 내부 파밍 · 쿼터뷰 레벨 디자인 | 건물 = 튜토리얼 & 자원 파밍 → 외부 맵 확장 |
