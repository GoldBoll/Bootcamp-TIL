# 2026-07-17 ~ 07-19 팀 진행 기록 (통합) — 레벨 톤 파이프라인·가구 피드백 델리게이트 전환·UI 규격화

7/17(금)~7/19(일) 사흘간 CH4 프로젝트(TeamCarry)와 블로그 양쪽 모두 내 커밋이 없다. TIL 루틴이 끊긴 구간이라, 이 문서는 팀 저장소 커밋 로그를 근거로 한 **통합 기록**이다 — 개인 작업 서사가 아니라 팀 동향 요약 수준으로만 남긴다(그래서 발행본 없이 종합본만). 팀은 이 주말 동안 레벨 톤 파이프라인(MPC·MF), 가구 피드백 시스템 구조 개선, UI 규격화를 진행했고, 이 흐름은 다음 주 초의 라이팅 굽기 실험(7/20)과 곧장 이어진다.

## 날짜별 팀 커밋 요약

### 7/17 (금) — 레벨 소품·로딩 로직

- 레벨 담당: 트럭 개조([Add] 트럭개조), 로딩 관련 로직 수정. 커밋 5건(무메시지 2건 포함).

### 7/18 (토) — 레벨 톤 파이프라인과 가구 피드백 구조 개선

- 레벨 담당: **MF(머티리얼 펑션)·MPC(머티리얼 파라미터 컬렉션) 도입** — 레벨1 배경톤을 MPC 값으로 일괄 제어하도록 수정하고, 랜드스케이프에 숲 텍스처 추가. 밤에는 라이팅 전반 수정과 **포스트 프로세스 볼륨을 레벨별 느낌에 맞게 각각 조정**. 레벨마다 톤을 따로 만드는 대신 공용 파라미터로 묶는 방향으로 보인다.
- 가구·사운드 담당: **가구 피드백 시스템을 매 틱 감시에서 그랩 시스템의 델리게이트 구독 방식으로 변경**, 거리 감쇄를 위한 사운드 어테뉴에이션 적용, 금 가는 메시 텍스처 변경 (fix/furniture-feedbacksystem 브랜치, 이후 PR #153으로 머지).

### 7/19 (일) — UI 규격화와 브랜치 합류

- UI 담당: **전체 UI 디자인 수정·폰트 크기 규격화**, UI 명세 파일 수정, 로딩 창 버그 해결. PR #151(레벨)·#152(UI)·#153(가구 피드백) 머지도 UI 담당이 진행.
- 레벨 담당: 머티리얼 벗겨진 부분 재지정, 로비 레벨 디자인·라이팅 조절.

## 관찰 — 커밋 로그에서 눈에 띈 것

1. **틱 폴링 → 델리게이트 구독**: 가구 피드백이 매 틱 상태를 감시하던 구조에서 그랩 시스템의 델리게이트를 구독하는 이벤트 구동으로 바뀌었다. 감시 비용을 없애고 발생 시점도 정확해지는 방향. 이 피드백 시스템은 7/8에 내가 "팀 파일 무수정" 제약 때문에 관찰(감시) 기반으로 만든 것인데, 그랩 시스템 쪽 델리게이트를 구독할 수 있게 되면서 관찰 부분이 이벤트 구동으로 대체된 것으로 보인다 — 부착 구조(서브시스템+컴포넌트)는 유지된 채 감시 지점만 바뀌었다.
2. **레벨 톤의 데이터화(MPC·MF)**: 레벨별 색감을 머티리얼 개별 수정이 아니라 파라미터 컬렉션으로 끌어올렸다. 스테이지가 L_Level1/L_Level2로 늘어난 직후(7/16 스테이지 체계 개편)라 시점이 맞다.
3. **주말 라이팅 작업의 결말은 다음 주에**: 이 주말의 라이팅·PPV 손질에 이어, 7/20에 라이트맵 베이크를 시도했다가 UV 채널·해상도·공유 메시 3중 원인을 추적하고 결국 "이 프로젝트는 굽지 않는다"로 결론 내는 과정은 [7/20 TIL](/posts/til-lightmap-bake-failure/)에, 로비 맵 프리로드가 ServerTravel과 충돌해 입장을 막은 사건은 [7/21 TIL](/posts/til-lobby-map-preload-travel-conflict/)에 정리했다.
